# Testing Documentation - Dog Nanny

Документация по тестированию приложения Dog Nanny согласно стандартам Quality Assurance.

---

## Testing Model

Приложение тестируется по следующим направлениям:
- Functional Testing (функциональное тестирование)
- Usability Testing (юзабилити тестирование)
- Performance Testing (тестирование производительности)
- Compatibility Testing (тестирование совместимости)

---

## 1. Functional Testing

### 1.1 Детекция звуков (ML mode)

#### Test Case 1: Детекция лая собаки
- Тип: Positive test
- Шаги:
  1. Запустить приложение
  2. Нажать "Начать мониторинг"
  3. Воспроизвести видео с лаем собаки на YouTube
  4. Наблюдать детекцию
- Ожидаемый результат: Приложение детектирует лай, счётчик увеличивается
- Критерий успеха: Detection rate >= 70%
- Статус: PASS (8/10 детекций)

#### Test Case 2: Фильтрация музыки
- Тип: Negative test
- Шаги:
  1. Запустить мониторинг
  2. Включить музыку (различные жанры)
  3. Наблюдать отсутствие детекции
- Ожидаемый результат: Музыка НЕ детектируется как лай
- Критерий успеха: False positive rate < 15%
- Статус: PASS (1/10 ложных срабатываний)

#### Test Case 3: Фильтрация речи
- Тип: Negative test
- Шаги:
  1. Запустить мониторинг
  2. Говорить в микрофон (обычная громкость)
  3. Наблюдать отсутствие детекции
- Ожидаемый результат: Речь НЕ детектируется как лай
- Критерий успеха: False positive rate < 10%
- Статус: PASS (0/10 ложных срабатываний)

#### Test Case 4: Фильтрация бытовых звуков
- Тип: Negative test
- Шаги:
  1. Запустить мониторинг
  2. Воспроизвести звуки: хлопки, стук двери, шум воды
  3. Наблюдать отсутствие детекции
- Ожидаемый результат: Бытовые звуки НЕ детектируются
- Критерий успеха: False positive rate < 20%
- Статус: PASS (1/10 ложных - громкий хлопок)

### 1.2 Управление порогом

#### Test Case 5: Изменение порога детекции
- Шаги:
  1. Установить порог 50 дБ
  2. Воспроизвести тихий звук
  3. Установить порог 80 дБ
  4. Воспроизвести тот же звук
- Ожидаемый результат: При низком пороге детектируется, при высоком - нет
- Статус: PASS

### 1.3 Переключение режимов

#### Test Case 6: Режим "Частоты"
- Шаги:
  1. Выбрать режим "Частоты"
  2. Воспроизвести лай собаки
  3. Проверить детекцию и метаданные
- Ожидаемый результат: Детекция работает, отображаются частотные данные
- Статус: PASS

#### Test Case 7: Режим "ML+Частоты"
- Шаги:
  1. Выбрать режим "ML+Частоты"
  2. Воспроизвести лай собаки
  3. Проверить детекцию и ML score
- Ожидаемый результат: Детекция работает, отображается ML confidence
- Статус: PASS

### 1.4 История и статистика

#### Test Case 8: Добавление в историю
- Шаги:
  1. Детектировать несколько лаев
  2. Проверить список истории
- Ожидаемый результат: Каждая детекция добавляется с временем
- Статус: PASS

#### Test Case 9: Удаление ложных срабатываний
- Шаги:
  1. Детектировать 5 событий
  2. Удалить 2 записи
  3. Проверить счётчики
- Ожидаемый результат:
  - Подтверждённых: 3
  - Ложных: 2
  - Точность: 60%
- Статус: PASS

## Known Issues

1. Низкочастотные звуки (< 200 Гц) через динамики искажаются
   - Severity: Low
   - Workaround: Тестировать на реальных звуках

2. ML score иногда низкий для записей через динамики
   - Severity: Low
   - Workaround: Использовать режим "Частоты"
